# 원스트라이크원볼 숫자야구

초등학생이 로컬에서 바로 실행해서 놀 수 있는 숫자야구 웹앱입니다.

## 목표

- 컴퓨터가 난이도에 맞춰 0~9 중 서로 다른 숫자를 고릅니다.
- 아이가 서로 다른 숫자를 입력하면 스트라이크/볼/아웃 힌트를 보여줍니다.
- 목표 스트라이크 수를 모두 맞히면 “정답! 홈런!”으로 게임이 끝납니다.
- 빨리 맞힐수록 점수와 별을 더 많이 받고, 연속 홈런 기록과 배지를 모읍니다.

## 난이도

- 초급: 0~9 숫자 중 서로 다른 3자리, 목표 3S입니다. 처음이면 추천합니다.
- 중급: 0~9 숫자 중 서로 다른 4자리, 목표 4S입니다.
- 상급: 0~9 숫자 중 서로 다른 5자리, 목표 5S입니다.
- 최상급: 0~9 숫자 중 서로 다른 6자리, 목표 6S입니다.

모든 난이도에서 0을 사용할 수 있고, 같은 숫자는 한 번만 쓸 수 있습니다. 난이도를 바꾸면 확인창 없이 새 게임으로 초기화됩니다.

## UX 구조

- 데스크톱 화면은 스크롤 없는 1페이지 구성을 목표로 합니다.
- 좌측에는 숫자 선택, 난이도, 입력창, 숫자 버튼, 점수와 진행도를 배치했습니다.
- 우측에는 기록이 쌓이는 기록판을 배치했고, 최근 시도는 아래로 누적됩니다.
- 기록판은 데스크톱에서 2열 20칸 고정 슬롯으로 보이며, 최대 20개 기록을 왼쪽 1~10칸에 먼저 채우고 그다음 오른쪽 11~20칸을 채웁니다.
- 빈 기록 칸도 번호가 보이므로 아이가 몇 번째 도전인지 쉽게 알 수 있습니다.
- 기록판은 20칸을 한 화면에 맞추도록 조정했습니다.
- 규칙은 항상 펼쳐두지 않고, 필요할 때만 “규칙 보기”를 눌러 확인한 뒤 다시 접기 가능한 구조입니다.
- 난이도 버튼은 초급/중급/상급/최상급 이름만 남겨 작게 만들고, 난이도 설명은 규칙 보기 내부로 옮겼습니다.
- 안내 메시지 패널을 제거해 확보한 공간을 숫자 버튼 영역에 더 많이 배정했습니다.

## 게이미피케이션 요소

- 점수: 난이도가 높을수록 기본 점수가 높고, 적은 도전 횟수로 맞히면 보너스를 받습니다.
- 별: 빠르게 맞히면 3개, 보통이면 2개, 오래 걸리면 1개를 받습니다.
- 연속 홈런: 정답을 맞힌 판 수가 이어서 올라갑니다.
- 배지: 진행도와 정답 결과에 따라 “새싹 타자”, “홈런왕”, “에이스”, “도전왕” 메시지를 보여줍니다.
- 효과: 숫자 입력 후 “던지기!”를 누르면 작은 효과음이 나고, 정답을 맞히면 축하 메시지와 컨페티 효과가 나옵니다.
